上游站点连不上时（网络抖动、站点抽风），插件数着连续失败次数「熔断」： 期间你的请求不再发给上游干等，而是立刻回 429，让 Claude Code 这类 agent 按它自带的退避策略自动重试；熔断窗口过后放行一个请求去试探，一通就恢复 放行、后续重试自动停止。整个过程不需要你盯着终端。

判定只看「连不连得上」：上游回了话——哪怕是 401、429——都算网络正常， 熔断立刻解除。网关给 agent 报的连接失败（502/504）和上游自己的 5xx 计失败。

边界：如果 agent 自己的重试也耗尽了、终端已经报错停下，那一轮对话任何插件 都救不回来，需要你手动重发。这个插件做的是让 agent 的耐心撑过更长的抖动。

隐私：熔断状态只是几个数字，记在 magpie 网关进程的内存里，不上盘、不发网、 不读你的对话内容。
